# Contributing

## Report a problem

Open an issue with your operating system, app version and steps to reproduce the problem. Explain what you expected and what happened. Remove personal data from screenshots and logs.

## Make a change

Fork the repository and branch from `main`. Keep changes focused and discuss larger features in an issue first.

Follow the existing code and keep the app local and uncluttered. The [development guide](docs/development.md) covers building and testing. Documentation edits do not need an app build.

Open a pull request against `main` with the change, checks you ran and sample screenshots for visual changes.

Link your commit email to GitHub to receive credit for merged contributions.
