# Contributing

## Report a problem

Open an issue with your operating system, meLearner version and steps to reproduce the problem. Explain what you expected and what happened. Add a screenshot or log if it helps, but remove private course names and personal data.

## Make a change

Fork the repository and create a branch from `main`. Keep each change focused. Discuss larger features in an issue before building them.

Follow the existing code and keep the app local, simple and uncluttered. Use the [development guide](docs/development.md) to build and run the relevant checks. Documentation edits do not need an app build.

Open a pull request against `main`. Explain the change and the checks you ran. For visual changes, include screenshots using sample courses.

Use a commit email linked to your GitHub account so merged contributions can appear in GitHub's Contributors list.
