# meLearner

Watch your courses offline.

Play videos and audio, read lessons and keep your progress on your device.

![Your course library in meLearner](docs/images/home.png)

![A lesson in meLearner](docs/images/course.png)

Screenshots use sample courses.

## Get started

1. Open meLearner.
2. Choose your course folder.
3. Pick a lesson.

## Downloads

Planned installers: Windows EXE · macOS DMG · Linux AppImage.

New installers are not available yet. [Earlier Linux downloads](https://github.com/WhiteHades/melearner/releases/latest) contain version 0.1.8. For the current app, see [Linux setup](docs/install.md).
